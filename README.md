# VOID STRIKE — космический шутер для Яндекс Игр

Тактический шутер от первого лица (Three.js): 7 видов оружия, 20 процедурных скинов, кейсы, 4 режима, 2 карты, гранаты, онлайн и бои с ботами.

## Режимы
- **Все против всех** — до 25 убийств.
- **Командный бой** — до 35 убийств.
- **Гонка вооружений** — каждое убийство даёт следующее оружие, победа за убийство клинком.
- **Заминирование** — раунды без возрождения, экономика и магазин (B в фазе подготовки, клавиши 1–8, там же гранаты), закладка/разминирование заряда (E) на точках A и B, смена сторон после 5-го раунда.

## Запуск локально
```bash
npm install
npm run build          # собирает dist/
node server/server.js  # игровой сервер на :8787
cd dist && python3 -m http.server 8080   # открыть http://localhost:8080
```
Локально клиент сам подключается к `ws://localhost:8787`.

## Карты
Обе карты рассчитаны по масштабу и структуре на тактический режим в стиле CS: примерно 96×120 м, высокие стены, арки-двери, лестницы, ящики для запрыгивания, бочки, контейнеры, мешки с песком.
- **Колония Дюна** — три линии (длинный коридор на западе, центральный коридор, туннели на востоке), плаза с площадкой в центре, два двора, площадки A и B на севере.
- **Рудник Кратер** — городские кварталы: узкие улицы, «рынок» с крышей на лестницах, дворы A и B за арками.

Карту выбирают на экране «Играть». Онлайн комнаты разделены по режиму и карте.

## Гранаты
`4` — осколочная, `5` — светошумовая, `6` — дымовая (на телефоне кнопка GR). В дезматче, командном бою и гонке вооружений выдаются по одной при возрождении. В «Заминировании» их покупают в магазине (B → клавиши 6–8, цены 300/200/300), они сохраняются, пока вы живы. Урон, ослепление и дым считает сервер; у ботов гранаты тоже работают.

## Свой сервер для онлайна (нужен для Яндекс Игр)
Игре нужен постоянно работающий сервер с защищённым **wss://**. Готовые файлы лежат в проекте: `Dockerfile`, `render.yaml`, `fly.toml`.

### Вариант 1: Render (есть бесплатный тариф)
1. Залейте проект в свой репозиторий на GitHub (вся папка, `node_modules` не нужен).
2. На render.com: **New → Blueprint**, выберите репозиторий. Render найдёт `render.yaml` и соберёт `Dockerfile`.
3. Когда сервис запустится, адрес будет вида `https://voidstrike-server.onrender.com`. Откройте `/health` — должно вернуться `{"ok":true,...}`.
4. Ваш адрес для игры: `wss://voidstrike-server.onrender.com`.
Бесплатный сервис Render засыпает без трафика, первое подключение после простоя занимает около минуты. Для постоянной работы возьмите платный тариф.

### Вариант 2: Fly.io
```bash
fly launch --no-deploy --copy-config   # имя приложения можно поменять
fly deploy
```
Адрес: `wss://ИМЯ-ПРИЛОЖЕНИЯ.fly.dev`.

### Вариант 3: свой VPS
```bash
git clone <ваш репозиторий> && cd voidstrike
npm install --omit=dev
PORT=8787 node server/server.js        # лучше под pm2 или systemd
```
Поставьте перед ним Caddy или nginx с TLS и проксируйте WebSocket на порт 8787.

### Подключение клиента
В `public/config.js` замените `wss://YOUR-SERVER-DOMAIN` на адрес сервера, выполните `npm run build`, заархивируйте **содержимое** `dist/` (index.html в корне архива) и загрузите в консоль разработчика Яндекс Игр. В консоли включите для игры доступ к вашему домену, если площадка это требует.

## Публикация в Яндекс Игры
Материалы для модерации (иконка, обложка, скриншоты, описание, чек-лист) лежат в папке `yandex/`.

1. Поднимите сервер (см. выше), проверьте `https://домен/health`.
2. Пропишите адрес в `public/config.js` и пересоберите (`npm run build`).
3. Загрузите содержимое `dist/` как ZIP в консоли Яндекс Игр.
4. SDK подключается автоматически (`/sdk.js`): язык, реклама (межстраничная и с наградой), облачные сохранения, лидерборд `kills` (создайте его в консоли).

## Управление
WASD, мышь, ЛКМ огонь, ПКМ прицел/удар клинком, R перезарядка, 1/2/3 оружие, 4/5/6 гранаты, F осмотр, Ctrl присесть, Shift тихий шаг, Tab таблица, E заряд. На телефоне — экранные кнопки.

## Структура
- `shared/` — оружие, карта, физика, логика матча (общая для клиента и сервера)
- `server/server.js` — комнаты, боты (считаются у хоста), проверка урона на сервере
- `src/` — клиент: рендер, скины, модели оружия, ИИ ботов, HUD, меню

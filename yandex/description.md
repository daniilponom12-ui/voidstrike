# VOID STRIKE — материалы для модерации Яндекс Игр

## Название
VOID STRIKE — космический тактический шутер

## Краткое описание (RU)
Космический тактический FPS в духе CS: закладка бомбы, закупка оружия, гранаты, три карты, боты и онлайн-матчи. 30+ видов оружия, скины, кейсы и ранги.

## Полное описание (RU)
VOID STRIKE — тактический шутер от первого лица на космической станции. Играйте против ботов или онлайн с друзьями: Бомба (закладка/обезвреживание, закупка, смена сторон), Командный бой, Бой насмерть, Гонка вооружений. Три большие карты, гранаты (осколочная, ослепляющая, дымовая), оружие с проработанными моделями, скины, кейсы, ранги и таблица лидеров.
Управление: WASD — движение, мышь — прицел, ЛКМ — огонь, R — перезарядка, B — закупка, 4/5/6 — гранаты, Tab — таблица. На телефоне — сенсорное управление.

## Description (EN)
VOID STRIKE is a tactical first-person space shooter inspired by classic bomb-defusal games. Buy weapons, throw grenades, plant or defuse the bomb on three large maps. Play against bots or online. Weapon skins, cases, ranks and a leaderboard.

## Чек-лист перед публикацией
- [ ] В `public/config.js` указан реальный `wss://` адрес сервера, затем `node build.mjs`
- [ ] Архив: `dist/` целиком в ZIP, `index.html` в корне, размер < 10 МБ (сейчас ~0,7 МБ)
- [ ] Игра запускается в iframe, SDK: `LoadingAPI.ready()` и `GameplayAPI.start/stop` вызываются (src/yandex.js)
- [ ] При сворачивании вкладки игра ставится на паузу и звук отключается
- [ ] В консоли разработчика создана таблица лидеров с именем `kills` (если нужна кнопка «Топ»)
- [ ] Проверено на телефоне (альбомная ориентация) и на ПК
- [ ] Возрастной рейтинг: 12+ (стилизованное насилие без крови)
- [ ] Включён HTTPS-сервер (wss://), `/health` отвечает «ok»
